Chat themes

The themes listed on the ChatZone tab. Players open chat groups inside a theme. General is always listed and cannot be changed or removed. The game joins the theme a player was in last as soon as the tab opens, so a player who was in a theme you remove sees "Der Wechsel in die Gruppe hat nicht geklappt" once and picks another. A theme for one language is shown only to games in that language (the language the game reports when it connects).

Permanent chat groups {% if are_groups_on %}on{% else %}off{% endif %}

Chat groups the server keeps open in a theme, marked [Server] in the game, so players can chat at once instead of opening a group first. They never close and nobody can take them away; players may still open their own next to them. Every new theme starts with one named after it.
