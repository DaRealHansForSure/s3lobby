Checks every generated text passes

  • Built only from text that was checked when it was stored: player names (letters and single spaces), clan and season names (check_game_text), numbers and dates. Nothing a client typed into the chat goes in.
  • Checked again as a whole before it is stored or sent: Windows-1252 only, no control characters but line breaks, at most 1200 bytes. A text that fails is logged and not posted.
  • Too long: whole lines are dropped from the end; a text is never cut inside a line.
  • Once per event: each text is stored with its event (season and kind, or the week), so a restart never posts it twice.
  • Chat commands /rank, /top, /clanrank, /seasons: a rate limit per player, arguments cut to 64 characters, answers fitted to the game's chat lines.
  • The web pages escape every name, and every form carries the CSRF token.
